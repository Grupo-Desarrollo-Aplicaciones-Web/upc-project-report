# Recursos visuales

Organización recomendada:

```text
assets/
├── architecture/  # C4, Event Storming y diagramas de clases
├── branding/      # Logos, colores e identidad
├── database/      # Diagramas de base de datos
├── interviews/    # Evidencias autorizadas de entrevistas
├── research/      # Lean UX, personas, journeys y empathy maps
├── sprints/       # Capturas de ejecución, commits y despliegues
└── ux/            # Wireframes, mockups, wireflows y user flows
```

Usa nombres descriptivos, por ejemplo `c4-context-diagram.png` o `sprint-01-backend-deployment.png`.
