## Revisarlo en GitHub Desktop

Abrir `creditor-web-app`, seleccionar `develop` y entrar en **History**. El nombre del autor principal alterna entre los tres; el correo vinculado permite a Desktop resolver el perfil cuando tenga la información disponible. No hace falta realizar un push para leer el historial local.

```sh
git shortlog -sne develop
git log --graph --format='%h | %an <%ae> | %s' develop
git show -s --format=fuller HEAD
```

Usar `develop` para el conteo. `git log --all` también incluye los respaldos y puede mostrar versiones duplicadas de un mismo cambio. El conteo del campo Author es distinto del conteo de coautores o responsables técnicos.
