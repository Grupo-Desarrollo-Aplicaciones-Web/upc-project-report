## External provider result and corrections

The authenticated BCRP endpoint returned HTTP 200. It reported an observation dated `2026-10-26` and preserved the provider attribution and retrieval timestamp. Its quote is a reference, not an executed currency conversion.

The initial live check exposed BCRP returning diagnostic HTML after JSON for an unrecognized/missing User-Agent. The adapter now sends a compatible identified client and requests JSON. It continues to reject contaminated responses. Regression tests cover the real payload, client identification, missing observations, Spanish/English month names, invalid dates, cache behavior, cancellation, staleness and century boundaries.

Other defects caught and corrected by verification: query-prefix binding in list/CSV search; global OpenAPI bearer security incorrectly inherited by public onboarding; and payload-too-large errors being converted to HTTP 400.
