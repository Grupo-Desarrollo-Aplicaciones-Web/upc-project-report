# Evidencias de entrevistas

Cada entrevista autorizada debe almacenarse o enlazarse con el código del participante, por ejemplo `s1-01-consentimiento.md` y `s1-01-captura.png`. El video se mantiene privado en Microsoft Stream; en el informe se coloca únicamente el enlace autorizado, su minuto de inicio y duración.

No subir documentos financieros, vouchers, números de cuenta, direcciones ni grabaciones sin consentimiento expreso.
